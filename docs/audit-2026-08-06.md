### Build environment note

During this pass, the working tree contained in-progress, uncommitted changes
from a concurrent session (a Caregiver live-location `MapView` feature using
`maplibre-gl`, visible via `git status` as untracked/modified files this
session did not create: `src/MapView.tsx`, `MapView.md`, and diffs to
`server/src/app.ts`, `server/src/routes/caregiver.ts`, `src/App.tsx`,
`src/api.ts`, `src/main.tsx`). That in-progress work referenced the
`maplibre-gl` package, which was not yet installed, and used two
`MapOptions` fields (`antialias`, `preserveDrawingBuffer`) not present in the
installed `@types/maplibre-gl` typings — this made `npm run build` fail
locally while that work was mid-flight. To keep this release-readiness audit
unblocked without disrupting the concurrent work, `maplibre-gl` and
`@types/maplibre-gl` were installed and the two non-existent option fields
were removed so the build succeeds. **This audit does not commit, review, or
take ownership of the Caregiver map feature itself** — it is left for its
own session to complete and commit. Only the audit's own deliverables (this
document, the other new `docs/*.md` files, the negative-test suite, and
`docs/screenshots/`) are part of this session's commit.
